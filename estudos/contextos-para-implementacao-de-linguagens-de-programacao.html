//! Contextos (Γ): associam nomes a bindings.
//!
//! O binding `B` depende do uso: um tipo na tipagem (`Γ ⊢ t : T`), um

Nós: contextos enquanto listas

Uma das formas mais clássicas, e primárias, de implementação de contextos utiliza listas encadeadas. Um contexto \( \mathbb{C} \) é um ponteiro \( \mathbb{head} para o início de uma lista encadeada de /possíveis/ nós \( \mathbb{n} \) de ligações \( \mathbb{b} \), mais o seu tamanho, i.e. 

// Nó de uma lista encadeada de ligações B
struct Node<B> {
    name: String,
    binding: B,
    parent: Option<Rc<Node<B>>>,
}

// Contexto sobre uma definição ~B~ de ~Binding<A, B>~
pub struct Context<B> {
    head: Option<      // possível valor, ou nada
           Rc<         // ponteiro para
            Node<B>    // nó de uma ligação 
           >
          >,
    len: usize,        // tamanho da lista encadeada
}

O contexto vazio \( \mathbb{C}_\emptyset \) é definido pelo construtor 

// Implementação para um tipo de ligação B
// de Contexto sobre ligações B
impl<B> Context<B> {
    // Construtor do contexto vazio
    pub fn empty() -> Self {
        Self { head: None, len: 0 }
    }

Acessamos o tamanho do contexto pela função abaixo, e a utilizamos para definir o predicado is_empty, verdadeiro quando não há ligação \( \mathbb{b} \) alguma no contexto atual. 

pub fn len(&self) -> usize {
    self.len
}


pub fn is_empty(&self) -> bool {
    self.len == 0
}
