Erros

Atualmente, as condições de erro implicam a tentativa de construção de um grafo impossível, ou mal-formado. Seja \( G = (N, A) \) um grafo, então

  1. Erro RightNodeNotInGraph se \( a \in A \land a' \notin A \implies \false \), isto é, se a primeira componente de um arco for um nó que está no grafo, enquanto a segunda componente não pertencer ao grafo, então é impossível adicionar a nova aresta ao grafo.
  2. Erro LeftNodeNotInGraph
  3. Erro BothNodesNotInGraph
  4. Erro DirectedCycleDetected
#[derive(Debug, Clone, PartialEq, Eq)]
pub enum GraphError {
    LeftNodeNotInGraph,
    RightNodeNotInGraph,
    BothNodesNotInGraph,
    DirectedCycleDetected,
}

Representação para Erros

impl fmt::Display for GraphError {
    fn fmt(&self, f: &mut fmt::Formatter<'_>) -> fmt::Result {
        match self {
            GraphError::LeftNodeNotInGraph => {
                write!(f, "cannot add edge: left node does not belong to the graph")
            }
            GraphError::RightNodeNotInGraph => {
                write!(f, "cannot add edge: right node does not belong to the graph")
            }
            GraphError::BothNodesNotInGraph => {
                write!(f, "cannot add edge: neither left nor right node belongs to the graph")
            }
            GraphError::DirectedCycleDetected => {
                write!(f, "cannot compute topological order: directed cycle detected")
            }
        }
    }
}

impl Error for GraphError {}

Definições

Um nó Node genérico sobre T. Acessamos seu conteúdo através de seu campo value. Nós são conectados por arcos Arc, genérico sobre T. Espera-se um T coincidente em Node<T> e Arc<T>. 

#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub struct Node<T> {
    pub value: T,
}


#[derive(Debug, Clone, PartialEq, Eq, Hash)]
pub struct Arc<T> {
    pub left:  Rc<Node<T>>,
    pub right: Rc<Node<T>>,
}

impl<T> Arc<T> {
    pub fn new(left: Rc<Node<T>>, right: Rc<Node<T>>) -> Self {
        Self { left, right }
    }
}
